# Run the TUV model with specified options

Run the TUV model with specified options

## Usage

``` r
tuv(
  depth_m = NULL,
  lat = NULL,
  lon = NULL,
  elev_m = NULL,
  date = NULL,
  Kd_ref = NULL,
  Kd_wvl = NULL,
  DOC = NULL,
  aq_env = c("freshwater", "marine"),
  tzone = 0L,
  tstart = 0,
  tstop = 23,
  tsteps = 24L,
  wvl_start = 280,
  wvl_end = 500,
  wvl_steps = wvl_end - wvl_start + 1,
  o3_tc = NULL,
  tauaer = NULL,
  ...,
  tuv_dir = tuv_data_dir(),
  quiet = FALSE
)
```

## Arguments

- depth_m:

  depth at which to calculate the light attenuation coefficient.
  Required.

- lat:

  latitude of the site, decimal degrees. Required.

- lon:

  longitude of the site, decimal degrees. Required.

- elev_m:

  elevation of the site above sea level, in metres. If `NULL` (default)
  it is looked up using a digital elevation model using lat and lon.

- date:

  date of the calculation, as `Date` object, or a character in a
  standard format that can be converted to a `Date` object (e.g.,
  "YYYY-MM-DD"). Required.

- Kd_ref:

  Light attenuation coefficient at reference wavelength. In freshwater,
  can be set directly, or calculated from `DOC`. In marine waters, it is
  calculated from the marine model for the location and date
  ([`marine_kd_model()`](https://bcgov.github.io/pahwq/reference/marine_kd_model.md))
  unless set here.

- Kd_wvl:

  The reference wavelength at which `Kd_ref` was obtained, in nm.
  Default `305` in freshwater, where it is only used if `Kd_ref` is set,
  and `375` in marine waters, where if only `Kd_wvl` is set, `Kd_ref` is
  recalculated from the model at that wavelength, and the attenuation
  curve is unchanged.

- DOC:

  dissolved organic carbon concentration, in mg/L. Ignored if `Kd_ref`
  is set directly.

- aq_env:

  Aquatic environment: "freshwater" (default) or "marine"? If "marine",
  the light attenuation is calculated from models for the ecoregion,
  water type, and season of the site (see
  [`marine_kd_model()`](https://bcgov.github.io/pahwq/reference/marine_kd_model.md)).
  `DOC` cannot be set. `Kd_ref`, `Kd_wvl` and `Sk` (passed in `...`) can
  be set to override the model: those not set come from the model. Where
  the model has no data, `Kd_ref` and `Sk` must be set. A warning is
  given when the model is flagged as having few valid pixels across the
  area (`VPFAREA`) or over time (`VPFTIME`).

- tzone:

  timezone offset from UTC, in hours. Default `0`.

- tstart:

  start time of the calculation, in hours. Default `0`.

- tstop:

  stop time of the calculation, in hours. Default `23`.

- tsteps:

  number of time steps to calculate. Must be between `1` and `24`,
  default `24`.

- wvl_start:

  start wavelength of the calculation, in nm. Default `280`.

- wvl_end:

  end wavelength of the calculation, in nm. Default `500`.

- wvl_steps:

  number of wavelength steps to calculate. Default 1 step per nm from
  `wvl_start` and `wvl_end`, inclusive.

- o3_tc:

  The ozone column, in Dobson Units. If `NULL`, it is looked up based on
  latitude and month, based on historic climatology. If there is no
  historic value for the given month and location, a default value of
  300 is used. You can force the use of this default by setting the
  value of this parameter to the string `"default"`.

- tauaer:

  The aerosol optical depth (tau) at 550 nm. If `NULL`, it is looked up
  based on latitude, longitude, and month, based on historic
  climatology. If there is no historic value for the given month and
  location, a default value of 0.235 is used. You can force the use of
  this default by setting the value of this parameter to the string
  `"default"`.

- ...:

  other options passed on to the TUV model. See
  [`tuv_aq_defaults()`](https://bcgov.github.io/pahwq/reference/tuv_aq_defaults.md).
  This includes `Sk`, the slope of the exponential decay of Kd with
  wavelength (nm^-1).

- tuv_dir:

  the directory where the compiled TUV executable is located

- quiet:

  Should the progress of the TUV program be printed to the console?

## Value

A data.frame with the results of the TUV run. It contains columns
specifying wavelength and calculated Kd(lambda), and a column for each
timestamp containing the irradiance at that time and wavelength, in W
m-2 nm-1.

For marine runs, the `kd_model` attribute is a one-row data frame
describing the marine light attenuation model used (see
[`marine_kd_model()`](https://bcgov.github.io/pahwq/reference/marine_kd_model.md)):
`area`, `ecoregion`, `water_type`, `season`, `Kd_ref`, `Kd_wvl`, `Sk`,
`r2`, the quality flags `nodata`, `peak`, `vpf_area`, and `vpf_time`,
and `dist_km`. `Kd_ref`, `Kd_wvl`, and `Sk` are the values used,
including any overrides.
