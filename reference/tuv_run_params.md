# Show the input parameters used for a TUV model run

Show the input parameters used for a TUV model run

## Usage

``` r
tuv_run_params(x)
```

## Arguments

- x:

  tuv results, a result of running
  [`run_tuv()`](https://bcgov.github.io/pahwq/reference/run_tuv.md)

## Value

a named character vector of the inputs to the TUV model
