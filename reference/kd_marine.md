# Calculate Kd at a given wavelength in marine waters.

Calculate Kd at a given wavelength in marine waters.

## Usage

``` r
kd_marine(wavelength)
```

## Arguments

- wavelength:

  lambda wavelength in nm

## Value

A numeric vector representing Kd at a given wavelength in marine waters

## Examples

``` r
kd_marine(400)
#>  400 
#> 0.35 
```
