# Calculate Kd at 305 nm for a given Dissolved Organic Carbon (DOC) concentration.

Calculate Kd at 305 nm for a given Dissolved Organic Carbon (DOC)
concentration.

## Usage

``` r
kd_305(DOC)
```

## Arguments

- DOC:

  DOC in g/m^3

## Value

A numeric vector representing Kd at 305 nm

## Examples

``` r
kd_305(5)
#> [1] 10.67
```
